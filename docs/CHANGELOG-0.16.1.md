# SIEGE 0.16.1 — Multiplayer despejado

Esta versión modifica únicamente la interfaz Multiplayer.

## Cambios visibles

- Cabecera reducida a título y cantidad de servidores.
- Eliminado el rótulo repetido de destino oficial.
- Panel derecho reducido a nombre, protección, estado e IP.
- El mensaje del servidor sólo aparece cuando aporta información.
- Eliminados los duplicados de nombre, estado, versión y MOTD.
- El pie de estado sólo aparece en diseños compactos sin panel lateral.
- Fila de red local reducida a una sola línea y con fondo opaco.
- Fondo general oscurecido para mejorar la lectura.
- `BORRAR` pasa a llamarse `ELIMINAR`.
- Editar y Eliminar permanecen desactivados para el servidor oficial.
- Al señalar cada control bloqueado se explica por qué no está disponible.
- El estado `Offline` se presenta como `SERVIDOR APAGADO`, no como versión incompatible.
- La dirección oficial permanece fijada en `SiegeLacontinuacion.exaroton.me:18736`.
- Se conserva el comportamiento vanilla de lista, ping, LAN y conexión.
